# Project meeting

**Wednesdays, 7:00 PM, Teams.** Thirty minutes. If it runs past forty, we are
solving a problem that should have been an issue in the repository instead.

Class is our second weekly contact. We do not need a formal agenda for that one.

---

## Agenda (fixed, in this order)

**1. What shipped since last meeting.** One sentence each, by role. Merged pull
requests only. Work in progress is not shipped.

**2. What is blocked.** Name the task number, name who you are waiting on, and
name what you need from them. "I'm stuck" is not a blocker report.

**3. What we decide today.** Only items that need more than one person. Anything
decided goes into `docs/DECISION_LOG.md` before the meeting ends, not after.

**4. Next week's commitments.** Each person names the task numbers they will
finish by the next meeting.

---
